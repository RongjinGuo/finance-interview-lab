# 财务面试练习室

中文财务模拟面试、逐题练习与复盘。账号版支持按用户保存答题进度，管理员可以查看练习记录。

请通过独立应用地址打开并登录：
https://rongjin03-finance-interview-lab.hf.space/

输入邀请码即可登录对应的练习账号。应用在 Space 上运行，邀请码校验值与答题记录保存在单独的私有仓库。运行所需密钥只通过 Space Secrets 配置，不包含在公开源码中。Space 重启会结束登录会话，已经完成云端保存的记录仍可在重新登录后读取。
